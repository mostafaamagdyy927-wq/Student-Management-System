# Student Record Management & GPA Calculation System

A C++ desktop application designed to simplify student academic record management through a graphical user interface (GUI).

## Features
- Student information management (Add, Edit, Delete, Search).
- Course management.
- Grade recording and management.
- Semester GPA and Cumulative GPA calculation.
- Academic performance reports.
- Interactive dashboard and statistics.

## Technologies
- C++
- Qt 6 (Qt Widgets)
- SQLite
- CMake
- Git & GitHub

## Project Structure
- `docs/` – Project documentation and requirements.
- `src/` – Application source code.
- `ui/` – User interface files.
- `resources/` – Images and icons.
- `tests/` – Testing files.
