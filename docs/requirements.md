# Student Record Management & GPA Calculation System

## 1. Project Overview
A C++ desktop application with a graphical user interface (GUI) designed to manage student academic records, courses, grades, and GPA calculations efficiently.

## 2. Main Objectives
- Manage student information.
- Organize courses and student enrollments.
- Record and update academic grades.
- Calculate Semester GPA and Cumulative GPA.
- Generate academic reports and statistics.
- Store and retrieve data using a database.

## 3. Functional Requirements

### 3.1 Student Management
- Add new students.
- Edit student information.
- Delete student records.
- Search for students.
- Display all registered students.

### 3.2 Course Management
- Add new courses.
- Update course information.
- Delete courses.
- Display available courses.
- Define course credit hours.

### 3.3 Grade Management
- Assign courses to students.
- Record student grades.
- Update grades.
- Display academic records for each student.

### 3.4 GPA Calculation
- Calculate Semester GPA.
- Calculate Cumulative GPA.
- Display academic performance.
- Determine academic standing.

### 3.5 Dashboard & Reports
- Display total number of students.
- Display total number of courses.
- Show average GPA.
- Display top-performing students.
- Generate student academic reports.

## 4. Non-Functional Requirements
- User-friendly graphical interface.
- Reliable data storage.
- Easy navigation between application sections.
- Organized and maintainable source code.
- Input validation and error handling.

## 5. Technologies
- Programming Language: C++
- GUI Framework: Qt Widgets
- IDE: Qt Creator
- Database: SQLite
- Build System: CMake
- Version Control: Git & GitHub

## 6. Project Scope
The system is intended for academic record management and GPA calculation. It is a desktop application developed as an educational team project.
